# Міграції

Файли `NNN_name.sql` застосовує сервіс `migrate` під час `docker compose up`: по черзі, кожен
один раз і в одній транзакції (`NNN_name.notx.sql` – без транзакції). Застосований файл не
змінюють. Для нової зміни схеми створюють новий файл.

```sh
docker compose run --rm migrate sh /migrate/migrate.sh --list
```

Каталог `examples/` містить схему й ресурси області «Міська бібліотека». Вони не
застосовуються автоматично.

Режими без захисту (`RESOURCE_MODE=unprotected`, `FENCING=off`) запускайте на окремих тестових
ресурсах. Обмеження бази не повинні приховувати досліджуваний механізм, а зіпсовані дані не
повинні змішуватися з робочими. `docker compose down -v` видаляє томи, і наступний запуск
створює базу заново.
